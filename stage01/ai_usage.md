# AI Usage

## AI Tool

Microsoft Copilot

## Tutor Prompt

I asked Microsoft Copilot to act as a Python tutor and explain my appointment-booking code.

I used the following prompt:

> Act as a Python tutor.
>
> I am learning introductory software technology.
>
> Here is a small appointment-booking function.
>
> 1. Explain what the code does.
> 2. Identify three limitations.
> 3. Suggest improvements.
> 4. Do not rewrite the whole application.
> 5. Ask me two questions to test my understanding.

## Alternative Code Prompt

I also asked Copilot to create a simple beginner-friendly Python function that stores a patient name, practitioner name and appointment time.

I specified that it should not use a database or GUI.

## How I Used AI

I used AI as a tutor to help me understand Python code, identify limitations and compare an AI-generated solution with my own solution.

I did not assume that the AI-generated code was correct. I ran the code and tested it using normal and unusual inputs. I then compared the results with my own version.
